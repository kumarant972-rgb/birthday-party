BIRTHDAY SURPRISE WEBSITE

Files:
- index.html: the complete, self-contained birthday website.

How to use:
1. Extract the ZIP file.
2. Open index.html in a browser to preview it.
3. To publish it as a shareable public website, upload index.html to a static hosting service.

Magic password: MAKEAWISH
The password gate is a playful surprise, not secure authentication.

Personalize before sharing:
- Replace [his nickname], [your name], [year], and the memory prompts in index.html.
- This package does not yet contain personal photos or the photo slideshow; add/upload photos to have those included in a later version.
